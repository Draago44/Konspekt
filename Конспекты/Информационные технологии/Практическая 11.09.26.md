## ПР №9. Работа с рисунками в документе

### Вставка рисунков

Вставить изображение в документ можно несколькими способами:

| Способ | Действие |
|---|---|
| Из файла | `Вставка` → `Изображение` → `Из файла...` |
| Перетаскивание | Протянуть картинку из проводника в документ |
| Из буфера | Скопировать изображение из браузера/программы → `Ctrl + V` |
| Сканирование | `Вставка` → `Изображение` → `Сканировать...` |

После вставки картинку можно:
- Перетаскивать мышью за край — изменить размер
- Держать `Shift` при растягивании — сохранить пропорции
- Переместить: выделите → зажмите и тяните в нужное место
- Обрезать: двойной клик по рисунку → редактирование

> [!tip] Сжатие изображений
> Большие фотографии утяжеляют файл. Сожмите их: `Формат` → `Изображение` → вкладка `Сжатие` → выбрать качество.

### Составление блок-схемы

Блок-схема — наглядное изображение алгоритма из соединённых фигур.

1. `Вид` → `Панели инструментов` → включите панель **Рисование**
2. На панели «Рисование» выберите нужные фигуры (прямоугольник — процесс, ромб — условие, овал — начало/конец)
3. Кликните и растяните фигуру на листе
4. Вставьте текст в фигуру: двойной клик по ней → наберите текст
5. Соедините фигуры стрелками с панели «Рисование»

> [!note] Связывающие линии
> Стрелки-соединители (линии с точками на концах) привязываются к фигурам: если переместить фигуру, линия «потянется» за ней сама.

### Переупорядочивание слоёв рисунка и вращение фигур

Каждый объект в документе лежит в своём «слое». Порядок слоёв определяет, что перекрывает что.

- Поднять объект выше: выделите → правая кнопка → `Порядок` → `Поднять на передний план` / `Поднять выше`
- Опустить ниже: правая кнопка → `Порядок` → `Опустить на задний план` / `Опустить ниже`

Вращение фигуры:
1. Выделите фигуру → наведите курсор на зелёный маркер над фигурой
2. Потяните его — фигура повернётся
3. Точный угол: `Формат` → `Положение и размер` → вкладка `Поворот` → указать градусы

### Создание рисунка-подложки для текста

Подложка (водяной знак) — полупрозрачный рисунок на фоне страницы, текст идёт поверх него.

1. Вставьте изображение, как обычно
2. Выделите его → правая кнопка → `Обтекание` → **«На задний план»** (в контекстном меню рисунка: `Обтекание` → `На заднем плане`)
3. Порядок → `Опустить на задний план`
4. Уменьшите непрозрачность: `Формат` → `Изображение` → вкладка `Прозрачность` → задать процент

> [!example] Эффект
> Получается «водяной знак»: логотип или надпись на заднем плане, поверх которого свободно набирается текст. Так оформляют бланки и дипломы.

### Управление обтеканием рисунка текстом

| Режим | Поведение текста |
|---|---|
| **Не обтекает** | Текст идёт выше и ниже рисунка, рядом не заполняется |
| **По контуру** | Текст обходит рисунок по его форме |
| **По рамке** | Текст обтекает прямоугольную границу рисунка |
| **На заднем плане** | Рисунок под текстом (подложка) |
| **Сквозное** | Текст проходит сквозь рисунок |

Настройка: выделите рисунок → правая кнопка → `Обтекание` → выберите режим. Точная настройка отступов текста от рисунка — там же → `Настройка обтекания`.

### Работа с научными формулами

Для формул в LibreOffice используется редактор **Math**:
1. `Вставка` → `Формула` (`Ctrl + Alt + O`)
2. Откроется окно редактора формул — введите команду, например `a^2 + b^2 = c^2`
3. Готовая формула появится в документе как объект

Основные команды Math:

| Команда | Результат |
|---|---|
| `a^2` | a в квадрате |
| `a_b` | индекс b |
| `sqrt{x}` | квадратный корень |
| `{a} over {b}` | дробь a/b |
| `sum from {i=1} to {n}` | сумма |
| `int dx` | интеграл |

> [!tip] Каталог формул
> В левой панели редактора Math есть каталог готовых шаблонов (дроби, корни, матрицы) — выбирайте элементы и заполняйте поля.

## Глава 2. Табличный процессор

### Табличный процессор. Определение

**Табличный процессор** — программа для обработки данных, представленных в виде таблицы: вычисления по формулам, построение диаграмм, анализ и сортировка.

> [!note] Отличие от Writer
> Текстовый процессор (Writer) работает с текстом, а табличный процессор (Calc) — с числами и формулами. Ячейки таблицы могут ссылаться друг на друга: изменение одних данных автоматически пересчитывает остальные.

Примеры: **LibreOffice Calc**, Microsoft Excel, Google Sheets.

Основные понятия:

| Понятие | Описание |
|---|---|
| **Книга** | Файл Calc, состоит из листов |
| **Лист** | Отдельная таблица (вкладка внизу окна) |
| **Ячейка** | Пересечение строки и столбца, адрес вида `A1`, `B2` |
| **Строка** | Горизонтальный ряд (1, 2, 3...) |
| **Столбец** | Вертикальный ряд (A, B, C...) |
| **Диапазон** | Прямоугольная область, например `A1:B5` |

### Создание книг и форматирование

1. Новая книга: `Файл` → `Создать` → `Электронная таблица` (`Ctrl + N`)
2. Новый лист: кнопка `+` рядом с вкладками листов внизу окна
3. Переименовать лист: двойной клик по вкладке → ввести имя
4. Сохранить: `Файл` → `Сохранить` (`Ctrl + S`) — формат `ODS` (родитель Calc) или `XLSX` (Excel)

**Форматирование ячеек:**
- Шрифт, размер, цвет — как в Writer (`Формат` → `Знаки`)
- Числа: `Формат` → `Ячейки` → вкладка `Числа` — процент, валюта, дата, дробные
- Выравнивание, перенос текста в ячейке — там же, вкладка `Выравнивание`
- Границы и заливка: вкладка `Обрамление` / `Фон` в окне `Формат` → `Ячейки`

> [!tip] Автозаполнение
> Потяните за маркер в правом нижнем углу выделенной ячейки (маленький квадратик) — Calc продолжит ряд: дни недели, месяцы, числа с шагом.

**Специальные возможности:**
- Навигация с клавиатуры без мыши (ячейки переключаются стрелками)
- Подписи на панелях («всплывающие подсказки»)
- Высокий контраст интерфейса через системную тему
- Чтение с экрана — поддержка скринридеров при настройке доступности

### Формулы VB (макросы)

**Макрос** — записанная последовательность действий, которую можно запускать одной кнопкой. В LibreOffice макросы пишутся на языке **Basic (VB-подобный)**.

Создание макроса:
1. `Сервис` → `Макросы` → `Управлять макросами` → `Basic...`
2. Задать имя макроса и нажать `Создать`
3. В открывшемся редакторе написать код

Пример макроса на Basic:

```basic
Sub Приветствие
    MsgBox "Здравствуйте!"
End Sub
```

Запись действий автоматически:
1. `Сервис` → `Макросы` → `Запись макроса`
2. Выполнить действия (оформить таблицу, вставить формулу)
3. Остановить запись → сохранить макрос

Запуск макроса:
- `Сервис` → `Макросы` → `Выполнить макрос` (F11 в старых версиях)
- Или назначить на кнопку панели инструментов

> [!note] Зачем нужны макросы
> Макросы автоматизируют повторяющиеся действия: заполнение однотипных таблиц, форматирование отчётов, обработку списков данных — вместо десятков кликов один запуск.
