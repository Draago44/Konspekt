### ПР №5. Управление просмотром документов

**Просмотр и перемещение внутри документа.**

В Word есть несколько способов перемещаться по большому документу:
- Колёсико мыши — прокрутка вверх/вниз
- Стрелки и клавиши `Page Up` / `Page Down` — постранично
- `Ctrl + Home` — в начало документа, `Ctrl + End` — в конец
- Навигационная панель (`Ctrl + F`) — поиск и переход по заголовкам

**Переход по закладке.**

Закладка — это именованная точка внутри документа, к которой можно вернуться в один клик.
1. Установите курсор в нужное место → `Вставка` → `Закладка`
2. Задайте имя и нажмите `Добавить`
3. Для перехода: `Вставка` → `Ссылки` → `Перейти` → выбрать закладку из списка

Закладки удобны для навигации в длинных документах — вместо того чтобы прокручивать сотни страниц, вы сразу попадаете в нужный раздел.

**Гиперссылки.**

Гиперссылка — кликабельная ссылка, которая ведёт на:
- Другой фрагмент того же документа (внутренняя ссылка)
- Веб-страницу
- Другой файл или даже конкретное место в другом файле

Создание: выделите текст → `Вставка` → `Ссылка` → укажите адрес или закладку. Быстрый способ — `Ctrl + K`.

### ПР №6. Оформление документа

**Создание титульного листа.**

Титульный лист — первая страница, содержащая:
- Название учебного заведения
- Тему работы
- Имя автора и руководителя
- Город и год

Оформляется вручную (центрирование, шрифт, размеры) или через готовые шаблоны Word (`Файл` → `Создать` → поиск «титульный лист»). Важно соблюдать требования ГОСТ или методических указаний вуза.

**Создание списка литературы.**

Список литературы — перечень источников, на которые ссылается автор. Оформляется по ГОСТ Р 7.0.5-2008 (библиографическая ссылка).

Порядок источников может быть:
- Алфавитный (по фамилии автора)
- По порядку упоминания в тексте

Каждый источник содержит: автор, название, издательство, год, страницы. В Word удобно вставлять через `Ссылки` → `Вставка ссылки` или вручную с отступом второй строки (абзац «висячий отступ» — 1.25 см).

### ПР №7. Страницы и разделы документа

**Разбивка документа на страницы.**

Длинный документ разбивается на логические страницы с помощью:
- Обычного переноса строки (`Enter`) — но это ненадёжно: при добавлении текста всё «поедет»
- Разрыва страницы (`Ctrl + Enter`) — принудительный переход на новую страницу, не зависит от объёма контента

**Разрывы страниц.**

Разрыв страницы — невидимый маркер, который заставляет следующий контент начаться с новой страницы. Найти его можно, включив отображение скрытых символов (значок `¶` на вкладке «Главная»).

**Нумерация страниц.**

Нумерация добавляется через: `Вставка` → `Колонтитулы` → `Номер страницы` → выбрать расположение (сверху, снизу, на полях).

Можно задать:
- Начальное значение (не с 1)
- Формат (арабские, римские цифры)
- Особый вид для титульного листа (без нумерации или с римскими)

### ПР №8. Продвинутая работа с документами

**Колончатые тексты.**

Колонки — способ расположить текст в несколько столбцов (как в газете). Настройка: `Разметка страницы` → `Колонки`. Удобно для буклетов, статей, справочников. Разрыв колонки: `Ctrl + Shift + Enter`.

**Внесение исправлений в текст.**

Word позволяет отслеживать правки без перезаписи оригинала:
- Режим «Отслеживание изменений» (`Ctrl + Shift + E`) — все правки отмечаются цветом
- Вы можете принять или отклонить каждое изменение: `Рецензирование` → `Принять` / `Отклонить`
- Комментарии добавляются выделением → `Рецензирование` → `Новый комментарий`

Это ключевой инструмент для совместной работы над документом.

**Составные документы и слияние документов.**

«Слияние документов» (Mail Merge) — создание множества однотипных документов из одного шаблона и базы данных:
1. `Рассылки` → `Начать слияние` → выбрать тип (письма, этикетки)
2. Указать источник данных (Excel, таблица Word, база данных)
3. Вставить поля слияния (ФИО, адрес и т.д.) в шаблон
4. Завершить и получить готовые документы

Применяется для массовой рассылки писем, создания дипломов, сертификатов.

**Колонтитулы.**

Колонтитулы — область сверху (верхний) или снизу (нижний) каждой страницы. Содержат:
- Номера страниц
- Название документа / главы
- Дату, логотип

Вставка: `Вставка` → `Колонтитулы`. Можно сделать разные колонтитулы для первой страницы и для остальных (галочка «Особый колонтитул для первой страницы»).

**Сноски и примечания.**

Сноска — маленький номер в тексте, ссылающийся на пояснение внизу страницы. Создание: `Вставка` → `Сноска`. Word автоматически нумерует сноски и размещает их внизу страницы.

Примечания — аналог сносок, но для электронных документов (отображаются при наведении).

**Создание оглавления.**

Оглавление — кликабельный список заголовков с номерами страниц. Чтобы его создать:
1. Заголовки документа должны быть оформлены через стили (`Заголовок 1`, `Заголовок 2` и т.д.)
2. Установите курсор в место, где будет оглавление
3. `Ссылки` → `Оглавление` → выбрать стиль

При изменении текста оглавление обновляется в один клик: `Обновить таблицу`. Это основное преимущество перед ручным оглавлением — оно всегда актуально.
