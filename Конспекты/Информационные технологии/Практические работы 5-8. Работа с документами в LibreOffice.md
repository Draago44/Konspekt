### ПР №5. Управление просмотром документов

**Просмотр и перемещение внутри документа.**

В LibreOffice Writer есть несколько способов перемещаться по большому документу:
- Колёсико мыши — прокрутка вверх/вниз
- Стрелки и клавиши `Page Up` / `Page Down` — постранично
- `Ctrl + Home` — в начало документа, `Ctrl + End` — в конец
- **Навигатор** (`F5` или `Вид` → `Навигатор`) — дерево заголовков и объектов, быстрый переход к любому разделу
- `Ctrl + F` — поиск по тексту

**Переход по закладке.**

Закладка — это именованная точка внутри документа, к которой можно вернуться в один клик.
1. Установите курсор в нужное место → `Вставка` → `Закладка`
2. Задайте имя и нажмите `Добавить`
3. Для перехода откройте Навигатор (`F5`) → вкладка «Закладки» → двойной клик по нужной закладке

Закладки удобны для навигации в длинных документах — вместо того чтобы прокручивать сотни страниц, вы сразу попадаете в нужный раздел.

**Гиперссылки.**

Гиперссылка — кликабельная ссылка, которая ведёт на:
- Другой фрагмент того же документа (внутренняя ссылка, через закладку)
- Веб-страницу
- Другой файл или даже конкретное место в другом файле

Создание: выделите текст → `Вставка` → `Гиперссылка` (`Ctrl + K`) → укажите адрес или закладку.

### ПР №6. Оформление документа

**Создание титульного листа.**

Титульный лист — первая страница, содержащая:
- Название учебного заведения
- Тему работы
- Имя автора и руководителя
- Город и год

Оформляется вручную (центрирование, шрифт, размеры) или через готовые шаблоны: `Файл` → `Шаблоны` → `Управление шаблонами`. Важно соблюдать требования ГОСТ или методических указаний вуза.

**Создание списка литературы.**

Список литературы — перечень источников, на которые ссылается автор. Оформляется по ГОСТ Р 7.0.5-2008 (библиографическая ссылка).

Порядок источников может быть:
- Алфавитный (по фамилии автора)
- По порядку упоминания в тексте

Каждый источник содержит: автор, название, издательство, год, страницы. В Writer можно вставить автоматическую библиографическую запись через `Вставка` → `Оглавление и указатели` → `Запись библиографии` или оформить вручную с «висячим отступом» второй строки (1.25 см) через `Формат` → `Абзац` → `Отступы и интервалы`.

### ПР №7. Страницы и разделы документа

**Разбивка документа на страницы.**

Длинный документ разбивается на логические страницы с помощью:
- Обычного переноса строки (`Enter`) — но это ненадёжно: при добавлении текста всё «поедет»
- Разрыва страницы (`Ctrl + Enter` или `Вставка` → `Разрыв страницы`) — принудительный переход на новую страницу, не зависит от объёма контента

**Разрывы страниц.**

Разрыв страницы — невидимый маркер, который заставляет следующий контент начаться с новой страницы. Найти его можно, включив отображение непечатаемых символов (значок `¶` на панели инструментов или `Ctrl + F10`).

**Нумерация страниц.**

В LibreOffice номера страниц вставляются через колонтитулы:
1. `Вставка` → `Верхний колонтитул` (по умолчанию)
2. Поставьте курсор в колонтитул → `Вставка` → `Поле` → `Номер страницы`

Можно задать:
- Начальное значение (не с 1): `Формат` → `Стили страницы` → вкладка `Страница` → «Вводить номер» и «Страница 1»
- Формат (арабские, римские цифры): там же → «Формат» в поле номера
- Особый вид для титульного листа: примените титульному листу стиль «Первая страница» (`Формат` → `Стили страницы` → двойной клик «Первая страница») и задайте в нём пустые колонтитулы

### ПР №8. Продвинутая работа с документами

**Колончатые тексты.**

Колонки — способ расположить текст в несколько столбцов (как в газете). Настройка: `Формат` → `Колонки` (применимо к странице, разделу или выделенному фрагменту). Удобно для буклетов, статей, справочников. Разрыв колонки: `Вставка` → `Разрыв` → `Разрыв столбца`.

**Внесение исправлений в текст.**

LibreOffice позволяет отслеживать правки без перезаписи оригинала:
- Режим записи изменений: `Правка` → `Отслеживание изменений` → `Записывать изменения` (`Ctrl + Shift + E`) — все правки отмечаются цветом
- Принять или отклонить каждое изменение: `Правка` → `Отслеживание изменений` → `Управление` → `Принять` / `Отклонить`
- Комментарии: выделить текст → `Вставка` → `Комментарий` (`Ctrl + Alt + C`)

Это ключевой инструмент для совместной работы над документом.

**Составные документы и слияние документов.**

«Слияние документов» (Mail Merge) — создание множества однотипных документов из одного шаблона и базы данных:
1. `Сервис` → `Мастер почтовых сообщений...` → выбрать тип (письма, этикетки)
2. Указать источник данных (Calc/Excel, таблица Writer, база данных)
3. Вставить поля слияния (ФИО, адрес и т.д.) в шаблон
4. Завершить и получить готовые документы

Применяется для массовой рассылки писем, создания дипломов, сертификатов.

**Колонтитулы.**

Колонтитулы — область сверху (верхний) или снизу (нижний) каждой страницы. Содержат:
- Номера страниц
- Название документа / главы
- Дату, логотип

Вставка: `Вставка` → `Верхний колонтитул` / `Нижний колонтитул` (нужно выбрать нужный стиль страницы). Разные колонтитулы для первой и остальных страниц делаются через стиль «Первая страница».

**Сноски и примечания.**

Сноска — маленький номер в тексте, ссылающийся на пояснение внизу страницы. Создание: `Вставка` → `Сноска`. Сноска в конец документа: `Вставка` → `Концевая сноска`. Writer автоматически нумерует сноски и размещает их внизу страницы.

Примечания (комментарии) — аналог сносок, но для электронных документов: `Вставка` → `Комментарий` (`Ctrl + Alt + C`).

**Создание оглавления.**

Оглавление — кликабельный список заголовков с номерами страниц. Чтобы его создать:
1. Заголовки документа должны быть оформлены через стили (`Заголовок 1`, `Заголовок 2` и т.д.)
2. Установите курсор в место, где будет оглавление
3. `Вставка` → `Оглавление и указатели` → `Оглавление, указатель или библиография...` → выбрать вид

При изменении текста оглавление обновляется: выделите его и нажмите `F9` (или через контекстное меню → `Обновить указатель`). Это основное преимущество перед ручным оглавлением — оно всегда актуально.
