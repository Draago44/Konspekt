# Практические работы 3–8. Работа с документами в LibreOffice Writer

---

## ПР №3. Проверка и форматирование текста

### Проверка орфографии и грамматики

LibreOffice Writer автоматически подчёркивает ошибки:
- Красное подчёркивание — **орфографическая** ошибка
- Зелёное подчёркивание — **грамматическая** ошибка

> [!tip] Быстрый запуск
> Нажмите `F7` — запустится проверка всего документа.

Для проверки:
1. `Инструменты` → `Правописание` (или `F7`) — проверка всего документа
2. Для проверки выделенного текста: правой кнопкой мыши → `Правописание`
3. Предлагаемые исправления — кликните по подсвеченному слову и выберите вариант

### Смена языка

Для корректной проверки нужно указать язык текста:
- Выделите текст → `Сервис` → `Язык` → `Для выделенного текста` → нужный язык
- Или в статусной строке (внизу окна) выберите язык для всего документа

> [!warning] Важно
> При работе с многоязычными документами обязательно указывайте язык — иначе проверка будет ругаться на правильные слова на другом языке.

### Расстановка переносов

Переносы разрывают длинные слова на конце строки знаком дефиса:
1. `Сервис` → `Язык` → `Расстановка переносов` → `Автоматическая`
2. Или вручную: `Сервис` → `Язык` → `Расстановка переносов` → `Вручную` — Writer покажет каждое слово и предложит место переноса

### Поиск и замена текста

| Комбинация | Действие |
|---|---|
| `Ctrl + F` | Быстрый поиск по документу |
| `Ctrl + H` | Поиск и замена (расширенный) |

> [!example] Пример
> Найти все «компьютер» и заменить на «Компьютер» с заглавной буквы — через `Ctrl + H` с включённым флагом «Учитывать регистр».

В расширенном режиме (`Ctrl + H`) можно:
- Заменять все вхождения сразу
- Искать по регулярным выражениям
- Заменять с учётом регистра

### Вставка специальных символов

- `Вставка` → `Специальный символ` — таблица символов (эмодзи, знаки, математические операторы)
- `Ctrl + Alt + X` — введите код символа и нажмите комбинацию (например, `20AC` → €)

Часто используемые символы:

| Символ | Название |
|---|---|
| © | Копирайт |
| ® | Товарный знак |
| № | Номер |
| ± | Плюс-минус |
| × | Умножение |
| → | Стрелка |
| — | Длинное тире |

## ПР №4. Работа со списками и стилями

### Маркированные списки

Маркированный список — перечень без нумерации.

Способы создания:
1. На панели инструментов нажмите значок маркированного списка (•)
2. `Формат` → `Список` → `Маркированный список`

Каждый новый абзац с включённым списком автоматически получает маркер. Для завершения списка — нажмите `Enter` дважды или отключите список кнопкой на панели.

### Нумерованные списки

Нумерованный список — элементы пронумерованы (1, 2, 3...).

1. Курсор в абзац → значок нумерованного списка (1.) или `Формат` → `Список` → `Нумерованный список`
2. Номера присваиваются автоматически — при вставке нового пункта нумерация обновится сама

### Автоматические списки

Writer распознаёт начало списка автоматически:
- Если вы напишете `1.` или `1)` и начнёте печатать — при нажатии `Enter` начнётся нумерованный список
- Аналогично с тире `—` или звёздочкой `*` для маркированного списка

> [!tip] Отключение авто-списков
> `Инструменты` → `Автозамена` → вкладка `Опции` → снять галочки с автоматических списков.

### Форматирование списков

Для настройки внешнего вида списка:
- `Формат` → `Список` → `Список` — изменение типа маркеров (кружки, квадраты, галочки), начального номера, отступов
- `Tab` — увеличить уровень вложенности
- `Shift + Tab` — уменьшить уровень вложенности
- Разные уровни списка могут иметь разные маркеры и форматирование

### Работа со стилями

Стиль — набор параметров форматирования (шрифт, размер, интервал, выравнивание), который применяется к тексту одним кликом.

Основные стили абзацев в Writer:

| Стиль | Описание |
|---|---|
| `Стандартный` | Обычный текст |
| `Заголовок 1` / `2` / `3` | Уровни заголовков |
| `Список` | Элементы списка |
| `Цитата` | Выделенная цитата |
| `Код` | Программный код |
| `Формула` | Математические формулы |

Применение: выделите текст → на панели стилей выберите нужный стиль.

### Создание своего стиля

1. Откройте панель стилей: `Формат` → `Стили` (или `F11`)
2. Правой кнопкой в области стилей → `Создать стиль` → ввести имя
3. Настроить: двойной клик по стилю → вкладки `Шрифт`, `Абзац`, `Страница`
4. Стиль можно создать на основе существующего — правой кнопкой → `Создать стиль` → выбрать «на основе»

> [!note] Преимущество стилей
> Стили обеспечивают единообразие документа: изменив стиль «Заголовок 1», вы обновите все заголовки сразу.

## ПР №5. Управление просмотром документов

### Просмотр и перемещение внутри документа

В LibreOffice Writer есть несколько способов перемещаться по большому документу:
- Колёсико мыши — прокрутка вверх/вниз
- Стрелки и `Page Up` / `Page Down` — постранично
- `Ctrl + Home` — в начало документа
- `Ctrl + End` — в конец документа
- **Навигатор** (`F5` или `Вид` → `Навигатор`) — дерево заголовков и объектов, быстрый переход к любому разделу
- `Ctrl + F` — поиск по тексту

### Переход по закладке

Закладка — именованная точка внутри документа, к которой можно вернуться в один клик.

1. Установите курсор в нужное место → `Вставка` → `Закладка`
2. Задайте имя и нажмите `Добавить`
3. Для перехода: Навигатор (`F5`) → вкладка «Закладки» → двойной клик по нужной закладке

> [!tip] Удобство
> Закладки позволяют мгновенно перейти к нужному разделу вместо прокрутки сотен страниц.

### Гиперссылки

Гиперссылка — кликабельная ссылка, которая ведёт на:
- Другой фрагмент того же документа (внутренняя ссылка, через закладку)
- Веб-страницу
- Другой файл или конкретное место в другом файле

Создание: выделите текст → `Вставка` → `Гиперссылка` (`Ctrl + K`) → укажите адрес или закладку.

## ПР №6. Оформление документа

### Создание титульного листа

Титульный лист — первая страница документа, содержащая:
- Название учебного заведения
- Тему работы
- Имя автора и руководителя
- Город и год

Оформляется вручную (центрирование, шрифт, размеры) или через готовые шаблоны: `Файл` → `Шаблоны` → `Управление шаблонами`.

> [!important] Требования
> Важно соблюдать требования ГОСТ или методических указаний вуза.

### Создание списка литературы

Список литературы — перечень источников, на которые ссылается автор. Оформляется по **ГОСТ Р 7.0.5-2008**.

Порядок источников:
- **Алфавитный** — по фамилии автора
- **По порядку упоминания** — по мере появления ссылок в тексте

Каждый источник содержит: автор, название, издательство, год, страницы.

В Writer можно вставить автоматическую библиографическую запись через `Вставка` → `Оглавление и указатели` → `Запись библиографии` или оформить вручную с «висячим отступом» второй строки (1.25 см) через `Формат` → `Абзац` → `Отступы и интервалы`.

## ПР №7. Страницы и разделы документа

### Разбивка документа на страницы

Длинный документ разбивается на логические страницы с помощью:
- Обычного переноса строки (`Enter`) — ненадёжно: при добавлении текста всё сдвигается
- **Разрыва страницы** (`Ctrl + Enter` или `Вставка` → `Разрыв страницы`) — принудительный переход на новую страницу

### Разрывы страниц

Разрыв страницы — невидимый маркер, который заставляет следующий контент начаться с новой страницы. Найти его можно, включив отображение непечатаемых символов (значок `¶` на панели инструментов или `Ctrl + F10`).

### Нумерация страниц

В LibreOffice номера страниц вставляются через колонтитулы:
1. `Вставка` → `Верхний колонтитул`
2. Поставьте курсор в колонтитул → `Вставка` → `Поле` → `Номер страницы`

Настройки нумерации:

| Параметр | Где настроить |
|---|---|
| Начальное значение (не с 1) | `Формат` → `Стили страницы` → `Страница` → «Вводить номер» |
| Формат (арабские / римские) | Там же → «Формат» в поле номера |
| Пустые колонтитулы для титульного | Стиль «Первая страница» → пустые колонтитулы |

## ПР №8. Продвинутая работа с документами

### Колончатые тексты

Колонки — расположение текста в несколько столбцов (как в газете).

Настройка: `Формат` → `Колонки` (применимо к странице, разделу или выделенному фрагменту). Разрыв колонки: `Вставка` → `Разрыв` → `Разрыв столбца`.

### Внесение исправлений в текст

LibreOffice позволяет отслеживать правки без перезаписи оригинала:
- **Режим записи изменений:** `Правка` → `Отслеживание изменений` → `Записывать изменения` (`Ctrl + Shift + E`) — все правки отмечаются цветом
- **Принять/отклонить:** `Правка` → `Отслеживание изменений` → `Управление` → `Принять` / `Отклонить`
- **Комментарии:** выделить текст → `Вставка` → `Комментарий` (`Ctrl + Alt + C`)

> [!note] Совместная работа
> Это ключевой инструмент для совместной работы над документом.

### Составные документы и слияние документов

**Слияние документов** (Mail Merge) — создание множества однотипных документов из одного шаблона и базы данных:
1. `Сервис` → `Мастер почтовых сообщений...` → выбрать тип (письма, этикетки)
2. Указать источник данных (Calc/Excel, таблица Writer, база данных)
3. Вставить поля слияния (ФИО, адрес и т.д.) в шаблон
4. Завершить и получить готовые документы

Применяется для массовой рассылки писем, создания дипломов, сертификатов.

### Колонтитулы

Колонтитулы — область сверху (верхний) или снизу (нижний) каждой страницы. Содержат:
- Номера страниц
- Название документа / главы
- Дату, логотип

Вставка: `Вставка` → `Верхний колонтитул` / `Нижний колонтитул`. Разные колонтитулы для первой и остальных страниц — через стиль «Первая страница».

### Сноски и примечания

- **Сноска** — номер в тексте, ссылающийся на пояснение внизу страницы. Создание: `Вставка` → `Сноска`
- **Концевая сноска:** `Вставка` → `Концевая сноска` — автоматически нумеруется и размещается внизу страницы
- **Примечания (комментарии):** `Вставка` → `Комментарий` (`Ctrl + Alt + C`)

### Создание оглавления

Оглавление — кликабельный список заголовков с номерами страниц.

Чтобы его создать:
1. Заголовки документа должны быть оформлены через стили (`Заголовок 1`, `Заголовок 2` и т.д.)
2. Установите курсор в место, где будет оглавление
3. `Вставка` → `Оглавление и указатели` → `Оглавление, указатель или библиография...` → выбрать вид

> [!tip] Обновление оглавления
> При изменении текста выделите оглавление и нажмите `F9` (или контекстное меню → `Обновить указатель`). Оглавление всегда актуально — это главное преимущество перед ручным списком.
