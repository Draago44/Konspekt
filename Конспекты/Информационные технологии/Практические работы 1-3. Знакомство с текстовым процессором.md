# Практические работы 1–3. Текстовый процессор и редактирование документа

---

## Текстовый процессор. Общие сведения

### Определение

**Текстовый процессор** — программа для создания, редактирования, форматирования и печати текстовых документов.

> [!note] Отличие от блокнота
> В отличие от простых текстовых редакторов (Блокнот, Notepad), процессор умеет форматировать текст: менять шрифты, создавать таблицы, вставлять картинки, нумеровать страницы.

Примеры: **LibreOffice Writer**, Microsoft Word, Google Docs, WPS Office.

### Структура экрана

Основные элементы окна текстового процессора:

| Элемент | Назначение |
|---|---|
| **Строка заголовка** | Название документа и программы |
| **Панель меню** | Главные меню: Файл, Правка, Вставка, Формат... |
| **Панель инструментов** | Кнопки быстрого доступа к частым командам |
| **Линейка** | Горизонтальная и вертикальная — для отступов и отбивки полей |
| **Рабочая область** | Сам лист документа с курсором |
| **Полосы прокрутки** | Перемещение по документу |
| **Статусная строка** | Номер страницы, язык, масштаб |

### Меню и панели инструментов

Основные меню:

- **Файл** — создать, открыть, сохранить, распечатать
- **Правка** — отменить, копировать, вставить, найти
- **Вид** — масштаб, навигатор, режимы просмотра
- **Вставка** — таблицы, изображения, разрывы, колонтитулы
- **Формат** — шрифт, абзац, страница, стили
- **Сервис** — проверка орфографии, настройки

Панели инструментов можно включать/выключать: `Вид` → `Панели инструментов`. Основные — **Стандартная** и **Форматирование**.

## ПР №1. Создание и форматирование документа

### Создание и сохранение документа

1. Создать новый документ: `Файл` → `Создать` → `Текстовый документ` (или `Ctrl + N`)
2. Сохранить: `Файл` → `Сохранить` (`Ctrl + S`) → указать имя и место
3. Сохранить как другой формат: `Файл` → `Сохранить как` (`Ctrl + Shift + S`)

> [!tip] Форматы файлов
> - `ODT` — родной формат LibreOffice
> - `DOCX` — формат Microsoft Word
> - `PDF` — для печати и чтения, нельзя редактировать

### Разметка страницы

Параметры страницы: `Формат` → `Стили страницы` (или `Формат` → `Страница` в некоторых версиях).

Настраивается:
- Поля (левое, правое, верхнее, нижнее)
- Ориентация (книжная / альбомная)
- Размер бумаги (A4, A5)
- Формат нумерации страниц

### Шрифты

Для форматирования шрифта: выделите текст → панель «Форматирование» или `Формат` → `Знак`.

| Параметр | Описание |
|---|---|
| Гарнитура | Стиль начертания (Times New Roman, Arial...) |
| Размер | Высота символов в пунктах (обычно 12–14) |
| Начертание | Полужирный (B), курсив (I), подчёркнутый (U) |
| Цвет | Цвет символов и выделения |
| Регистр | Заглавные/строчные буквы |

### Списки и таблицы

- Списки: кнопка «Маркированный список» (•) или «Нумерованный список» (1.) на панели или `Формат` → `Список` (см. [[Практические работы 1-3. Знакомство с текстовым процессором|ПР №3]])
- Таблицы: `Вставка` → `Таблица` (`Ctrl + F12`) → указать количество строк и столбцов

### Специальные возможности

Writer доступен для людей с ограниченными возможностями:
- **Проверка специальных клавиш** — настройки повторного нажатия клавиш (`Сервис` → `Доступность`)
- **Навигация с клавиатуры** — все команды доступны без мыши
- **Высокий контраст тем** — настраивается через тему оформления
- **Подсказки при наведении** — объяснение кнопок панелей

## ПР №2. Редактирование документа

### Выделение блоков текста

| Действие | Как сделать |
|---|---|
| Слово | Двойной клик по слову |
| Строка | Тройной клик по строке |
| Абзац | Четыре клика по абзацу |
| Произвольный фрагмент | Зажать левую кнопку мыши и протянуть |
| Весь документ | `Ctrl + A` |
| Расширить выделение | `Shift` + стрелки |
| Вся строка | `Shift + End` / `Shift + Home` |

### Операции с выделенным текстом

Над выделенным фрагментом можно выполнять операции:

| Операция | Горячая клавиша |
|---|---|
| Вырезать | `Ctrl + X` |
| Копировать | `Ctrl + C` |
| Вставить | `Ctrl + V` |
| Удалить | `Del` / `Backspace` |
| Отменить | `Ctrl + Z` |
| Повторить | `Ctrl + Y` |
| Форматировать | Панель «Форматирование» |

Копирование с форматом или без — после вставки появляется кнопка выбора вида вставки (сохранить/объединить/очистить формат).

### Контекстное меню

Правая кнопка мыши открывает контекстное меню — команды зависят от того, где кликнули:
- В тексте: вырезать/копировать/вставить, правописание, формат
- В таблице: вставить строку/столбец, объединить ячейки
- На картинке: обрезка, обтекание текстом

> [!tip] Удобство
> Контекстное меню — самый быстрый способ применить действие к объекту: команды уже подобраны под текущее место документа.

### Масштабирование рабочего окна

- `Ctrl` + колёсико мыши — изменение масштаба
- Статусная строка → значки «–» / «+» — плавная регулировка
- `Вид` → `Масштаб` → выбрать процент (75%, 100%, 200%...) или «По ширине страницы»

### Форматирование абзацев

Абзац — блок текста между нажатиями `Enter`. Настройка: `Формат` → `Абзац`.

| Параметр | Описание |
|---|---|
| Выравнивание | По левому / центру / правому / ширине |
| Отступ слева/справа | Сдвиг всего абзаца |
| Первая строка (красная) | Отступ первой строки («красная строка») |
| Междустрочный интервал | Одинарный, 1.5, двойной |
| Интервал до/после | Отступ абзаца от предыдущего/следующего |

### Работа с линейкой

Горизонтальная линейка управляет отступами абзаца — на ней есть 3–4 ползунка:
- **Двойной треугольник сверху** — отступ первой строки
- **Треугольник снизу** — отступ всего абзаца слева
- **Квадратик под ним** — двигает оба сразу
- **Ползунок справа** — отступ справа

Ползунки удобно таскать мышью: отпустите — отступы применятся к текущему абзацу (или выделенным).

### Режим предварительного просмотра

Перед печатью стоит посмотреть, как документ будет выглядеть на бумаге:
- `Файл` → `Предварительный просмотр` (или `Ctrl + Shift + O`)
- Или `Файл` → `Печать` → кнопка **Предпросмотр**

В этом режиме видно целиком страницы, поля, разрывы — можно заметить ошибки вёрстки до того, как потратить бумагу.

## ПР №3. Работа со списками и стилями

### Маркированные списки

Маркированный список — перечень без нумерации.

Способы создания:
1. На панели инструментов нажмите значок маркированного списка (•)
2. `Формат` → `Список` → `Маркированный список`

Каждый новый абзац с включённым списком автоматически получает маркер. Для завершения списка — нажмите `Enter` дважды или отключите список кнопкой на панели.

### Нумерованные списки

Нумерованный список — элементы пронумерованы (1, 2, 3...).

1. Курсор в абзац → значок нумерованного списка (1.) или `Формат` → `Список` → `Нумерованный список`
2. Номера присваиваются автоматически — при вставке нового пункта нумерация обновится сама

### Автоматические списки

Writer распознаёт начало списка автоматически:
- Если вы напишете `1.` или `1)` и начнёте печатать — при нажатии `Enter` начнётся нумерованный список
- Аналогично с тире `—` или звёздочкой `*` для маркированного списка

> [!tip] Отключение авто-списков
> `Инструменты` → `Автозамена` → вкладка `Опции` → снять галочки с автоматических списков.

### Форматирование списков

Для настройки внешнего вида списка:
- `Формат` → `Список` → `Список` — изменение типа маркеров (кружки, квадраты, галочки), начального номера, отступов
- `Tab` — увеличить уровень вложенности
- `Shift + Tab` — уменьшить уровень вложенности
- Разные уровни списка могут иметь разные маркеры и форматирование

### Работа со стилями

Стиль — набор параметров форматирования (шрифт, размер, интервал, выравнивание), который применяется к тексту одним кликом.

Основные стили абзацев в Writer:

| Стиль | Описание |
|---|---|
| `Стандартный` | Обычный текст |
| `Заголовок 1` / `2` / `3` | Уровни заголовков |
| `Список` | Элементы списка |
| `Цитата` | Выделенная цитата |
| `Код` | Программный код |

Применение: выделите текст → на панели стилей выберите нужный стиль.

### Создание своего стиля

1. Откройте панель стилей: `Формат` → `Стили` (или `F11`)
2. Правой кнопкой в области стилей → `Создать стиль` → ввести имя
3. Настроить: двойной клик по стилю → вкладки `Шрифт`, `Абзац`, `Страница`
4. Стиль можно создать на основе существующего — правой кнопкой → `Создать стиль` → выбрать «на основе»

> [!note] Преимущество стилей
> Стили обеспечивают единообразие документа: изменив стиль «Заголовок 1», вы обновите все заголовки сразу. Подробнее о связке стилей и оглавления — в [[Практические работы 3-8. Работа с документами в LibreOffice|следующей заметке]].
