# Организация рабочего места. Учётная запись, софт и выгрузка заметок

> [!important] Цель задания
> Подготовить защищённое рабочее место, установить нужное ПО и правильно сохранить заметки за последние три дня — в свой репозиторий и дополнительно, в другом формате.

---

## Шаг 1. Защищённая учётная запись на компьютере

Учётная запись — «паспорт» пользователя компьютера. Она должна быть защищена паролем или PIN-кодом.

Создание в Windows:
1. `Параметры` → `Учётные записи` → `Семья и другие пользователи` → `Добавить другого пользователя`
2. Создать пользователя **стандартного типа** (не администратора) для обычной работы
3. Задать пароль или PIN: `Параметры` → `Учётные записи` → `Параметры входа` → `Добавить PIN`

Создание в macOS:
1. `Системные настройки` → `Пользователи и группы` → замок → `+`
2. Выбрать тип «Стандартный», задать пароль
3. В macOS пароль запрашивается автоматически при входе и разблокировке

> [!warning] Зачем это нужно
> - Пароль/PIN защищает данные при оставленном без присмотра компьютере
> - Стандартная учётная запись (не администратор) не даст вирусу установиться без вашего подтверждения
> - Блокировка экрана: `Win + L` (Windows) или `Ctrl + Cmd + Q` (macOS)

## Шаг 2. Установка необходимого софта

| Программа | Назначение | Официальный сайт |
|---|---|---|
| **Obsidian** | Ведение заметок в Markdown | obsidian.md |
| **LibreOffice** | Текстовый и табличный процессор | libreoffice.org |
| **GitHub Desktop** | Управление репозиториями без командной строки | desktop.github.com |

Общие правила установки:
1. Скачивать ПО **только с официальных сайтов** (таблица выше)
2. В Windows запустить установщик `.exe`, в macOS — перетащить в папку «Программы»
3. При установке LibreOffice рекомендовано полное (стандартное) размещение
4. GitHub Desktop потребует авторизации через аккаунт GitHub при первом запуске

> [!note] GitHub Desktop
> Позволяет «закоммитить» (сохранить версию) и «запушить» (выгрузить) файлы в облачный репозиторий GitHub — удобно для резервной копии заметок.

## Шаг 3. Привести в порядок заметки за три дня и выгрузить

### 1. Навести порядок в заметках

- Собрать заметки за последние **три дня** в одну папку vault (например, `Информационные технологии`)
- Убрать пустые и черновые файлы, объединить дубли
- Проверить оформление: заголовки, теги, внутренние ссылки
- Убедиться, что файлы `.md` открываются и в Obsidian, и в LibreOffice (без потери структуры)

### 2. Выгрузка в свой репозиторий (папка «Информационные технологии»)

1. Создать репозиторий на GitHub (например, `Konspekt`, папка `Информационные технологии`)
2. Авторизоваться в GitHub Desktop
3. `File` → `Add local repository` → указать путь к папке с заметками
4. Написать сообщение коммита → `Commit to main`
5. `Push origin` — выгрузить заметки в облако

### 3. Выгрузка другим способом (например, PDF)

PDF — универсальный формат, который открывается везде и не «плывёт», в отличие от текстовых файлов.

- Из Obsidian: плагин экспорта → Экспорт в PDF (или через установленный плагин вывода)
- Из LibreOffice: `Файл` → `Экспорт в PDF` (`Ctrl + Shift + E`)
- Файлы `.pdf` загрузить, например, на Google Диск, в облако вуза или приложить к репозиторию GitHub

> [!important] Куда согласовать
> Место размещения PDF-файлов нужно **согласовать с преподавателем** или методистом — например, определённая папка в облаке, почта или система дистанционного обучения (Moodle и т.п.).
