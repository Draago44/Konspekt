# Погрешность измерения — конспект

## Введение
Погрешность измерения — это разность между измеренным значением величины и её опорным значением. Ранее термин определялся как отклонение результата измерения от истинного значения, но теперь он относится к характеристике точности измерения. Погрешность измерения не может быть точно определена, так как истинное значение измеряемой величины обычно неизвестно. Вместо этого используется действительное значение, полученное экспериментальным путём, которое близко к истинному значению и используется для оценки погрешности.
## Ключевые понятия
- **Погрешность измерения**: Разность между измеренным значением и истинным значением измеряемой величины.
- **Действительное значение**: Значение, близкое к истинному, полученное экспериментальным путём.
- **Абсолютная погрешность**: Величина, выраженная в единицах измеряемой величины, отклоняющаяся от истинного значения.
- **Относительная погрешность**: Отношение абсолютной погрешности к действительному значению измеряемой величины.
- **Инструментальная погрешность**: Погрешность, обусловленная несовершенством прибора.
- **Методическая погрешность**: Погрешность, связанная с несовершенством метода измерений.
- **Субъективная погрешность**: Погрешность, обусловленная ограниченными возможностями и ошибками человека.
- **Случайная погрешность**: Погрешность, изменяющаяся случайным образом в серии повторных измерений.
- **Систематическая погрешность**: Погрешность, изменяющаяся по определённому закону.
- **Грубая погрешность**: Погрешность, существенно превышающая ожидаемую, обусловленная явной ошибкой.
## Практическое значение
Погрешность измерения важна для оценки точности измерений и обеспечения качества результатов. Она помогает понять, насколько надёжны полученные данные и какие корректировки могут быть необходимы.
## Разделы по способу выражения
### Абсолютная погрешность
- Формула: \(\Delta X = X_{\text{измеряемый}} - X_{\text{истинный}}\)
- Используется для оценки отклонения измеренного значения от истинного.
- Вместо истинного значения используется действительное значение \(X_{\text{д}}\).
### Относительная погрешность
- Формула: \(\delta X = \frac{\Delta X}{X_{\text{д}}}\)
- Безразмерная величина, численное значение может указываться в процентах.
## Разделы по источнику возникновения
### Инструментальная погрешность
- Обусловлена несовершенством прибора, например, из-за неточной калибровки.
### Методическая погрешность
- Обусловлена несовершенством метода измерений, например, от неадекватности модели объекта или неточности расчётных формул.
### Субъективная погрешность
- Обусловлена ошибками человека при проведении измерений, например, в неточностях при отсчёте показаний со шкалы прибора.
## Разделы по характеру проявления
### Случайная погрешность
- Изменяется случайным образом в серии повторных измерений.
- Описывается теорией случайных процессов и математической статистикой.
- Уменьшается путём усреднения данных при увеличении количества измерений.
- Часто имеет нормальное распределение.
### Систематическая погрешность
- Изменяется по определённому закону.
- Обусловлена неисправностью или несовершенством приборов.
- Не может быть устранена повторными измерениями.
### Грубая погрешность
- Существенно превышает ожидаемую погрешность.
- Обусловлена явной ошибкой в проведении измерений.
- Исключается из рассмотрения и не используется при дальнейшей математической обработке.
## Итоги
1. Погрешность измерения важна для оценки точности и качества измерений.
2. Абсолютная и относительная погрешности используются для оценки отклонения измеренного значения от истинного.
3. Погрешности классифицируются по источнику возникновения: инструментальная, методическая, субъективная.
4. Случайные и систематические погрешности имеют разные характеристики и методы устранения.
5. Грубые погрешности исключаются из рассмотрения при обработке данных.
6. Понимание погрешностей помогает улучшить качество измерений и результатов.
